# Upgrade to Calcit 0.13.77

## English

- Upgraded the project toolchain to Calcit and `@calcit/procs` 0.13.77, and
  advanced the immutable Respo dependency to 0.16.91 without changing this
  package's 0.8.9 release version.
- Updated `first`/`last`/`nth` option handling exposed by 0.13.77 and added
  narrow schemas around string parsing/formatting helpers. Both the default and
  test entries now pass check-only validation; the dynamic-method audit dropped
  from six findings to three documented compatibility boundaries.
- Hardened CI with immutable dependency/toolchain verification, both entry
  checks, static baselines, all ten attached tests, generated JavaScript, and
  the Vite production build.
- Added formatter regressions for tagged routes, guidepost parameters, and 404
  paths. A production-build browser smoke test covered home, team, room, both
  search variants, and 404 with no console warnings or errors.
- Replaced the mutable third-party deployment action with explicit rsync over
  strict SSH. The checked-in `tiye.me` ED25519 key must occur exactly once and
  match the independently verified fingerprint before deployment.

## 中文

- 将项目工具链升级到 Calcit 与 `@calcit/procs` 0.13.77，并把不可变 Respo
  依赖升级到 0.16.91；本包发布版本仍保持 0.8.9。
- 修复 0.13.77 暴露的 `first`/`last`/`nth` Option 处理，并为字符串解析/格式化辅助函数补充窄化
  schema。默认与 test 入口均通过 check-only；动态方法审计从 6 处降至 3 处
  有文档说明的兼容边界。
- CI 现在验证不可变依赖与工具链、双入口、静态基线、全部 10 个附着测试、
  生成 JavaScript 以及 Vite 生产构建。
- 新增 tagged route、guidepost 参数与 404 路径的格式化回归测试。生产构建的
  浏览器 smoke test 覆盖 home、team、room、两种 search 与 404，控制台无
  warning/error。
- 用显式、严格 SSH 校验的 rsync 取代可变第三方部署 action；部署前要求仓库
  中的 `tiye.me` ED25519 键恰好出现一次，并匹配经独立核验的指纹。
